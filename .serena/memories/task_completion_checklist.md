# タスク完了時のチェックリスト

タスクを完了したら、以下のコマンドを実行して品質を確認してください。

## 1. リンター実行
```bash
pnpm lint
```
コードスタイルの問題を自動修正し、残りのエラーがないか確認します。

## 2. フォーマッター実行
```bash
pnpm format
```
コードフォーマットを統一します。

## 3. ビルド確認（大きな変更の場合）
```bash
pnpm build
```
TypeScriptエラーやビルドエラーがないか確認します。

## 4. 開発サーバーで動作確認
```bash
pnpm dev
```
変更が正しく動作するか確認します。

## 5. Storybook確認（UIコンポーネント変更時）
```bash
pnpm storybook
```
コンポーネントが正しく表示されるか確認します。

## 注意事項
- 新しいコンポーネントを作成した場合は、Storybookファイルも作成すること
- データベーススキーマを変更した場合は `pnpm db:push` と `npx prisma generate` を実行
- 未使用のインポートは自動的にエラーになるため、削除すること
